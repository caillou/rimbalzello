# pattern generator

## PRD

[2026-11-12-rimbalzello-v1](../prd.md)

## What to build

Grids' drum map ported in spirit to TypeScript as a pure function with no RNG and no state: position (x, y), three densities, three chaos perturbations and a step (0–31) in; hit and accent per drum out.

Port rules from the PRD (they decide the sound, so follow them exactly):

- Copy the 25 node arrays (96 bytes each) and the 5×5 placement permutation (`drum_map[5][5]`) exactly from Grids. Credit the source in a header comment; the file is GPL-3.0-or-later like the rest.
- Node lookup `x >> 6`, `y >> 6`. Interpolation mix(a, b, f) = (a × (255 − f) + b × f) >> 8 with f = (x << 2) & 0xff, masked to 8 bits for Grids' wraparound. x = 255 never reaches the far node exactly.
- Perturbation is passed in (the transport rolls it): random byte × (chaos >> 2) >> 8, at most 63. Provide that formula as a separate pure helper taking the random byte, so the transport does not duplicate it. Level plus perturbation clips to 255.
- Hit when the level passes the density threshold (same comparison as Grids); accent needs a hit and level above 192.
- Do not copy Grids' Euclidean table.

`handover-grids-peaks.md` lists the source files. Where it says the generator ticks per 16th note, read 32nd note: one pattern is 32 steps, one bar.

## Acceptance criteria

- [ ] Tests at node positions return that node's levels 2 below the stored value (Grids' 8-bit rounding) (checks the placement permutation, not nodes in order).
- [ ] Tests between nodes check interpolated levels, including a case that exercises the 8-bit wraparound, and that x = 255 does not equal the far node.
- [ ] Tests for density thresholds: density 0 gives no hits, density 255 gives a hit wherever the level is non-zero (or Grids' exact rule), and raising density never removes a hit.
- [ ] Tests for accents (level above 192 and a hit) and for perturbation clipping at 255 and the at-most-63 bound.
- [ ] No state and no RNG inside the module.
