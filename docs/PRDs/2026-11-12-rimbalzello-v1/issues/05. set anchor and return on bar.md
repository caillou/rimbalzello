# set anchor and return on bar

## PRD

[2026-11-12-rimbalzello-v1](../prd.md)

## What to build

The bottom bar's `set anchor` and `↺ return on bar` become live. `set anchor` snapshots the setup minus tempo into the anchor. `↺ return on bar` requests a return; the button pulses while the return is pending and stops when it lands at the next bar. Return before any set anchor restores the setup the session started with. Tempo and mutes are untouched. `↺ return on bar` is the one solid yellow block.

## User stories covered

40, 41, 42, 43, 44

## Acceptance criteria

- [ ] Playwright: set anchor, move a strip and the pad, press return; the return button reports a pending state until the next bar, then the strip value and X/Y readout are back to the anchored values and bpm and mutes are unchanged.
- [ ] Playwright: on a fresh load, changing the setup and pressing return restores the loaded setup.

## Notes from earlier reviews

- From the setup store review: pad undo swaps the pad position only, and a return never enters the undo slot. So an undo right after a return jumps to where the last pad move started, and a second undo goes back to the anchor's position. Try it by feel and decide whether a return should clear the undo slot.
