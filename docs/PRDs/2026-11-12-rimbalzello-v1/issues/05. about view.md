# about view

## PRD

[2026-11-12-rimbalzello-v1](../prd.md)

## What to build

The credits as an app state with its own URL, per the PRD's About page section, `design.md` (About) and `designs/08-about.png`.

- `// about` in the footer (the only entry) opens about over the app without stopping the music and pushes `/about/`; the setup hash stays on the URL.
- `← back to play · still playing`, `×`, `esc` and browser back return to `/` with the hash.
- Content: h1 `# rimbalzello`, one-line description, `## made from` (Grids and Peaks by Émilie Gillet, linked), `## made by` (Pierre Spring, caillou.ch), `## licence` (GPL-3.0-or-later, link to the source at the deployed commit using the injected hash, link to the third-party notices), footer `// source  // caillou.ch`, the not-affiliated note and "Mutable Instruments" trademark note. Blog-post styling; the about view may scroll.
- The build emits `/about/index.html` with the credits prerendered into the HTML, loading the same app with about open, so a direct visit or reload works on GitHub Pages before any JavaScript runs.
