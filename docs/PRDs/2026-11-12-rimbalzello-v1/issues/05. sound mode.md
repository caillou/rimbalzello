# sound mode

## PRD

[2026-11-12-rimbalzello-v1](../prd.md)

## What to build

`→ sound` swaps the strips for drum tabs `bd` `sd` `hh`: the active tab in its drum's colour with an underline and the drum's full name (`bass drum`, `snare drum`, `hi-hat`) in grey italics on the right. Below, that drum's sliders in two columns on phones (bd freq, punch, tone, decay, level; sd freq, tone, snappy, decay, level; hh level), in the drum's colour. Pad, step display and loop strip stay playable. The bottom bar's first item becomes `← play`, which returns to the strips. See `designs/v2-03-phone-sound.png`.

The sound slider group is built so the laptop layout can show all three side by side.
