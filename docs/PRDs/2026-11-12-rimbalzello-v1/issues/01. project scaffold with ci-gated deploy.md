## What to build

The empty repo becomes a buildable, tested, deployed static site, so every later issue lands on a green pipeline.

- Vite + Solid + TypeScript (strict). Engine code lives apart from UI code so the engine never imports Solid.
- Vitest for unit tests, Playwright for browser checks (Chromium, WebKit and Firefox projects), each with a script in `package.json` and one real test each so the runners are proven (for example a Playwright check that the page loads without console errors).
- GitHub Actions: on every push, typecheck, unit tests and Playwright run; on `main`, a green run deploys to GitHub Pages and a red run does not. `CNAME` for `rimbalzello.caillou.ch` ships in the build output.
- The build injects the deployed commit hash so the about view can link to the source at that commit later.
- IBM Plex Mono self-hosted (no font CDN), with the base colours from `design.md` as CSS variables and the resolution-dependent weights.
- Licence: `LICENSE` with GPL-3.0-or-later; a third-party notices file shipped in the build output listing Grids (GPL-3.0-or-later), IBM Plex Mono (OFL-1.1) and Peaks (MIT, only if code or tables get ported; leave a placeholder line otherwise). A README that states the licence, the dependency rule (permissive, LGPL or GPL-3-compatible only) and that MIT is a possible later step.
- Tunables module: the one place for every value tuned by ear or feel, each with a comment. Seed it with the initial setup (all fields of the setup, bpm 128, swing 56) and the lookahead (about 100 ms); later issues add their values here.
- The setup type (fields and ranges from the PRD's URL format table) and the default setup, so parallel issues share one definition.

The DNS record for the subdomain is outside the repo; note it in the README as a manual step. If the agent has `gh` access to the GitHub repo, enable Pages with the Actions source; otherwise note that step too.

## Acceptance criteria

- [ ] Tooling per AGENTS.md: Node from the existing `.nvmrc` (asdf legacy mode), pnpm pinned via `packageManager: pnpm@12.18.0` (via corepack), `pnpm-lock.yaml` committed, CI uses pnpm and the `.nvmrc` Node version.

- [ ] `pnpm install --frozen-lockfile && pnpm build` produces a static `dist/` with `index.html`, `CNAME`, the font files and the third-party notices.
- [ ] Typecheck, Vitest and Playwright each run locally and in CI; a deliberately failing test makes the CI run red and skips the deploy job.
- [ ] A push to `main` with green CI deploys to GitHub Pages.
- [ ] The built page can read the injected commit hash.
- [ ] `LICENSE` is GPL-3.0; every dependency in the lockfile passes the dependency rule (a CI step or script checks licences and fails on GPL-2.0-only or unlicensed packages).
- [ ] The tunables module exists with comments; the setup type and default setup live in engine code with no framework import.
