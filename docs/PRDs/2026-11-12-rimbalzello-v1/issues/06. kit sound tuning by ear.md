# kit sound tuning by ear

## PRD

[2026-11-12-rimbalzello-v1](../prd.md)

## What to build

Pierre tunes the kit on the deployed app, on his iPhone and laptop: voice parameter ranges and mappings, default sound, drift maximums, accent velocity, drive curve and gain compensation, glide length, and the default swing (56 %, fallbacks 54 % and 58 %). All changes go into the tunables module only. Direction: Peaks as the starting point, moving toward hard techno.

An agent can prepare candidate values and apply Pierre's notes; the sign-off is his.

## User stories covered

12, 29, 30, 31, 32, 33, 34

## Acceptance criteria

- [ ] Pierre signs off that bd, sd and hh sound usable across their parameter ranges.
- [ ] Pierre signs off that drift sounds warm at moderate settings and not broken at maximum, and that drive crunches without a big jump in loudness.
- [ ] Pierre confirms or replaces the default swing and glide length.
- [ ] Every changed value lives in the tunables module with an updated comment; the offline smoke tests still pass.
