# transport

## PRD

[2026-11-12-rimbalzello-v1](../prd.md)

## What to build

The pure, clock-injected transport replaces the tracer's scheduler, and the app now plays the generated pattern instead of the fixed groove. It owns tempo, swing, the playhead, the seeded RNG and time. Given the clock and a lookahead window it emits "play these hits at time t" events; a thin real-time wrapper drives it from `AudioContext.currentTime` and sends the events to the kit. It must stay free of Web Audio and DOM so it can move into an AudioWorklet later.

- **Playhead**: 32nd-note steps, 32 steps per bar, tempo 60–200 bpm. Play starts at step 0; tempo changes apply from the next step.
- **Chaos**: the RNG rolls the three perturbations (using the pattern generator's helper) when the playhead crosses step 0, and at play start.
- **Swing**: off-beat 16ths (step mod 4 = 2) are delayed by d = (p − 0.5) × 2 × the length of a 16th; steps with mod 4 = 1 or 3 shift by d/2. Swing applies to all drums and follows the playhead slot.
- **Glide**: a new pad target glides from the current position over the tunable glide length (one or two steps), starting at once; a jump during a glide starts a new glide from where the position is. Return jumps without gliding.
- **Return**: a pending return lands when the playhead next crosses step 0, applying the anchor's setup; the transport exposes whether a return is pending.
- Hits read the current pattern for the current setup at each step; accents set velocity (accent velocity in tunables).
- Leave a clear seam for the looper (which step index is read), built in the next issue.

## Acceptance criteria

- [ ] Tests with a fake clock, no real timers: at 128 bpm, hits land at step multiples of 60/128/8 s; a tempo change mid-bar changes spacing from the next step.
- [ ] Tests: at 120 bpm and 56 % swing, step 2 lands about 15 ms late, step 1 and 3 about 7.5 ms late, step 0 and 4 on the grid; at 50 % nothing moves.
- [ ] Tests: chaos re-rolls exactly once per bar, at step 0 (two bars with chaos > 0 and a fixed seed give different perturbations per bar, identical within a bar).
- [ ] Tests: a return requested at step 9 lands at the next step 0, not before; the position jumps (no glide); tempo and mutes are untouched.
- [ ] Tests: a jump reaches its target within the glide length and passes through intermediate positions; the first step after the jump already reads a moved position.
- [ ] The deployed app plays the generated pattern for the default setup after `▶ tap to play`.
