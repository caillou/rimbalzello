# setup in the url hash

## PRD

[2026-11-12-rimbalzello-v1](../prd.md)

## What to build

Sharing and persistence, wired end to end. The URL hash always holds the current setup through the URL codec, updated with `replaceState` at most once per second (trailing update so the last change lands), inside try/catch. On load: a valid or invalid hash always wins (an invalid one gives the default setup); without a hash, the last setup remembered on the device is used; otherwise the default. The anchor is set to whatever was loaded. Mutes are never in the URL.

## Acceptance criteria

- [ ] Playwright: open `/#v1.<payload>` for a known setup; strips, X/Y readout and bpm show those values.
- [ ] Playwright: change a strip; within about a second the hash changes and decodes to the new value; `history.length` did not grow.
- [ ] Playwright: change a setting, reload the bare `/`; the setting is back. Then open a link with a different hash; the link wins.
- [ ] Playwright: a malformed hash loads the default setup without errors.

## Notes from earlier reviews

- From the url codec review: `decodeSetup('')` returns the default setup, the same as a hash that decodes to the default. Check for an empty `location.hash` or a bare `#` before choosing between the setup remembered on the device and the default.
